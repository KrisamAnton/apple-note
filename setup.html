KrisNote

Ersteinrichtung – ersten Benutzer anlegen

Auf diesem Server ist noch kein Benutzer eingerichtet. Bevor du hier fortfährst, brauchst du den Einrichtungscode, den der Server beim Start ins Log geschrieben hat:
  • Docker: docker logs <containername> bzw. docker compose logs
  • systemd: journalctl -u krisnote -n 50 (Dienstname ggf. anpassen)
  • Sonst: im Terminal/Fenster, in dem der Server gestartet wurde
Suche dort nach der Zeile „Einrichtungscode:".

3–30 Zeichen: Buchstaben, Zahlen, "_", "-" und "."
